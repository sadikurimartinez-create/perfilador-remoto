# ADR-022.8K Crime Incidence Dataset Provenance

The Crime Incidence Admission Gate requires these server-side variables:

- `CRIME_INCIDENCE_DATASET_NAME`
- `CRIME_INCIDENCE_DATASET_VERSION`
- `CRIME_INCIDENCE_SOURCE_ORGANIZATION`
- `CRIME_INCIDENCE_DATASET_TEMPORAL_START`
- `CRIME_INCIDENCE_DATASET_TEMPORAL_END`

Use institutionally approved values only. Temporal values use `YYYY-MM-DD` and the start must not be after the end.

For local execution, define the values in `.env.local`, which is ignored by Git. For deployed execution, define the same keys in the Vercel project Environment Variables for each intended environment. Do not copy deployment values into tracked `.env.vercel*` files or client-side `NEXT_PUBLIC_*` variables.

Missing or invalid configuration intentionally leaves the dataset as `INCOMPLETE_PROVENANCE` or failed validation. This is a governance control and must not be bypassed.

## Institutional Provenance Declaration - C5i / 911

The admitted crime-incidence dataset is an operational dataset originating from the C5i, which is part of the Secretaría de Seguridad Pública del Estado de Aguascalientes.

Primary origin of the information:

- Emergency calls received through the 911 emergency service.
- Operational information captured by 911 service operators during event intake.
- Institutional producing unit: C5i.
- Parent institution: Secretaría de Seguridad Pública del Estado de Aguascalientes.
- Dataset nature: operational incident records derived from emergency reports received through 911.

For the currently admitted dataset, the canonical governance identifiers used by Perfilador Remoto are:

- CRIME_INCIDENCE_DATASET_NAME=Incidencia Delictiva 911 - Robo a Negocio - Aguascalientes
- CRIME_INCIDENCE_DATASET_VERSION=2025-C5I-911-v1
- CRIME_INCIDENCE_SOURCE_ORGANIZATION=C5i de la Secretaría de Seguridad Pública del Estado de Aguascalientes
- CRIME_INCIDENCE_DATASET_TEMPORAL_START=2025-01-01
- CRIME_INCIDENCE_DATASET_TEMPORAL_END=2025-12-31

DATASET_NAME is the canonical internal governance name used by Perfilador Remoto.

DATASET_VERSION identifies the first governed incorporation of the 2025 C5i/911 dataset into Perfilador Remoto. It must not be interpreted as an externally issued C5i document version.

The temporal coverage corresponds to the canonical dataset currently admitted after integrity validation.

Institutional provenance was expressly confirmed by the project authority on 2026-09-02. The dataset must not be attributed to SESNSP, because the operational 911/C5i dataset and the SESNSP statistical datasets are separate sources with different data models and provenance.
